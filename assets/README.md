# Assets — Maquette ODBI Academy

Placez ici les ressources visuelles utilisées par la maquette.

## YoDalf (assistant IA)

Déposez l'illustration de YoDalf dans ce dossier sous le nom exact :

```
assets/yodalf.png
```

Format conseillé : PNG carré (ex. 512×512). La maquette l'affiche
automatiquement comme avatar de YoDalf dans le chat. Tant que le fichier
est absent, un emoji 🧙 s'affiche en repli.
