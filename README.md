# ODBI Design System

> Stratège du facteur humain en haute intensité

## À propos

ODBI est un organisme de développement du potentiel humain en contexte de haute intensité. Ce design system définit les fondations visuelles et les règles d'usage de la marque ODBI.

---

## Couleurs

### Primaires

| Nom | Hex | Usage |
|-----|-----|-------|
| Asparagus | `#86A43F` | Couleur dominante — visuels formels, bannières, mission ODBI |
| Apple Green | `#B1BC4B` | Secondaire — accents, icônes, call-to-action subtils |

### Secondaires

| Nom | Hex | Usage |
|-----|-----|-------|
| Indigo Dye | `#114C6A` | Accent fort — CTA clés, contenus backstage |
| Jet | `#4D4D4D` | Texte principal, titres, fonds techniques |
| French Grey | `#A4A4A7` | Fonds minimalistes, visuels quotidiens |
| Alabaster | `#F0EEE6` | Fond général, base textes blancs |

### Catégories de contenu

| Catégorie | Hex | Description |
|-----------|-----|-------------|
| Business | `#86A43F` | Collaboration, partenariats, relations professionnelles |
| Sport | `#114C6A` | Effort, discipline, performance |
| Life | `#B1BC4B` | Soutien, épanouissement, croissance personnelle |
